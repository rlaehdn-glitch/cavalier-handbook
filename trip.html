동기화 경로는 /trip/{공유코드} 하나뿐입니다. 빼꼼이 핸드북이 쓰는 /handbook/{코드}는 건드리지 않으며, 핸드북과 같은 코드는 입력이 거부됩니다.

최초 1회 설정 — 한 사람만 (약 5분, 무료)

  1. console.firebase.google.com → 구글 로그인 → 프로젝트 만들기 (핸드북 프로젝트 재사용 가능)
  2. 빌드 → Realtime Database → 데이터베이스 만들기 → 위치 asia-southeast1 → 잠금 모드
  3. 규칙 탭을 아래 중 하나로 바꾸고 게시
  4. 데이터 탭 상단의 https://…firebasedatabase.app 주소를 복사 → 위 첫 칸에 붙여넣기
  5. “코드 생성”으로 공유 코드를 만들고 동기화 켜기 → 상대 폰에서도 같은 주소·같은 코드 입력

규칙 A — 이 대시보드만 쓰는 새 프로젝트 (/trip 전용)

{ "rules": {
  "trip": { "$code": { ".read": true, ".write": true } }
} }

규칙 B — 빼꼼이 핸드북과 같은 프로젝트 (/handbook + /trip 모두 허용)

{ "rules": {
  "handbook": { "$fam":  { ".read": true, ".write": true } },
  "trip":     { "$code": { ".read": true, ".write": true } }
} }

보안 판단: 규칙은 코드를 정확히 아는 경로(/trip/{코드})만 읽기·쓰기 허용이고 루트(/trip)에는 권한이 없어 코드 목록을 열람할 수 없습니다. 공유 코드가 곧 비밀번호입니다 — 16자 이상 랜덤 문자열을 쓰고, 핸드북 가족 코드와 같은 값은 쓰지 마세요. 두 폰에서 동시에 수정하면 나중에 저장한 쪽이 남습니다(입력 중인 기기는 6초간 상대 변경을 받지 않음).
